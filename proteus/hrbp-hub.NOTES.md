## §3 ПОЛЯ: ЧТО ЖДЁТ МАКЕТ ↔ ЧТО ДАЁТ SQL

Макет берёт всё из `data.js` (дерево, ряды метрик 24 мес + недели, цели, HRBP).
Датасет `hrbp-hub.data.sql` отдаёт то же одной выборкой: строки разных ролей.

| Поле, которое ждёт макет | Где в HTML | Есть в SQL? | Колонка SQL |
|---|---|---|---|
| дерево юнитов (NODES: path, name, level) | app.js 118–138 | да | role=dict, j (id, pid, lvl, hc, cur, rk, nm) |
| HRBP и их зоны (HRBP: scope, role) | app.js 139–150 | да | role=hrbps, j; meta.roots/role |
| ряды метрик юнита (24 мес) | app.js 67, 480 | да | role=scope/c/g/x, m_* (числитель/знаменатель) |
| недельные ряды (12+12 нед) | app.js 440 | да | role=scope/c/g/x, w_* |
| база сравнения (benchmarkSeries) | app.js 437 | да | role=base, m_*/w_* |
| цели и наследование (KPI_RULES) | app.js 84–116 | да | role=kpi, id/pid/j |
| значения разрезов (FILTER_DEFS) | app.js 167–175 | да | role=f, id/pid/n |
| разбивка по разрезу (cutMonthlySeries) | app.js 650–663 | да | role=tr, m_* |
| период (PERIOD_LABEL) | app.js 257 | да | meta.cal, meta.last_m |

Форма данных: не одна агрегатная строка, а пакет строк разных ролей (meta,
dict, hrbps, base, scope, c, g, x, f, tr, kpi). Массивы — строкой через запятую.

| Колонка в SQL | Тип | Alias в `CFG.fields` | Добавлена в «Измерения» |
|---|---|---|---|
| role | String | role | нет |
| id | String | id | нет |
| pid | String | pid | нет |
| n | Int64 | n | нет |
| j | String | j | нет |
| m_hc … m_fire (12) | String | fields.m.* | нет |
| w_hc … w_fire (12) | String | fields.w.* | нет |
