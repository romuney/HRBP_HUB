# FIELDS — поля для «Измерений» Proteus

Поля из SQL не попадают в `data` автоматически. Каждое поле ниже нужно вручную
добавить в панель «Измерения» с точным именем.

Правило синхрона: **имя в SQL == имя в «Измерениях» == ключ в `CFG.fields`**.
Любое расхождение — поле не дойдёт до графика (RETRO 17).

Типы в Proteus: `f(x)` — вычисляемое, `#` — число, `abc` — строка.

## Что считается в JS, а что в SQL

| Расчёт | Где считается | Почему | Кто согласовал |
|---|---|---|---|
| Числители/знаменатели по слотам, окна 12 мес / 52 нед и 3 мес / 13 нед | SQL (ноут в GP) | окна считаются по событиям сотрудников — в JS событий нет, только суммы | архитектура отчёта (docs/dataset-spec.md) |
| Сумма по юнитам зоны, −1 / −2, база, фасеты, разбивка по оси | SQL (датасет) | суммирование массивов по дереву — работа ClickHouse, в чарт едут итоги | архитектура отчёта |
| Проценты, средняя численность окна, дельты, светофор, ±5%, наследование целей, «Прочие» | JS | правило 2 скилла: база не пересчитывается на клик | по умолчанию |

## Настроить РУКАМИ в Proteus (skill этого не делает)

Это задачи ПОЛЬЗОВАТЕЛЯ, а не агента. Агент оставляет их пустыми `[ ]` и заполняет
только текст в скобках. Ставить `[x]` за пользователя ЗАПРЕЩЕНО: галочка означает
«в Proteus реально настроено», и ложная отметка прячет причину пустого виджета.

- [ ] Тип визуализации: ECHARTS (кастомный JS, код — `hrbp-hub.chart.js`).
- [ ] Измерения: все 29 полей из таблицы выше, точными именами.
- [ ] Сортировка: [не нужна — чарт раскладывает строки по role сам; метрик-сортировки не добавлять].
- [ ] Упорядочивание: [пусто].
- [ ] Сортировка по убыванию: [выкл].
- [ ] Лимит строк: [10 000 — ответ на компанию у супер-HRBP ≈1 000 строк (дерево «Команд» на 3 уровня, 17 осей трансформеров; справочник всей зоны — одна строка), но без лимита Proteus режет по умолчанию; meta должна приезжать всегда].
- [ ] Серверная пагинация: [выкл].
- [ ] Фильтры: [нет. Кросс-фильтр на самого себя ВКЛЮЧИТЬ: Edit dashboard → кросс-фильтры → чарт «HRBP HUB» в получателях собственного фильтра; иначе выбор юнита/разрезов/оси не применяется, чарт скажет об этом сам через 9 с].
- [ ] Кэш чарта: [по умолчанию; после пересчёта ноута кеш сбрасывает параграф «Обновить кеш борда»].
