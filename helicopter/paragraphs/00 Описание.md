### HRBP HUB — витрины отчёта для HRBP

Ноут собирает всё, что нужно единственному чарту отчёта HRBP HUB в Proteus, и
выгружает в ClickHouse (`prod_proteus.hrbp_hub_*`). Метрики — числитель и
знаменатель, время — массивы по 24 слота (месяцы и недели), оргструктура —
путь юнитов в каждой строке: компания (lvl1) и lvl3…lvl12 mapped-структуры, как в
ультраширокой. Проценты не храним: любая цифра отчёта — `Σ num / Σ den`.

#### Sources
- `prod_v_emart.mdm_employee_structure_d` — база всех метрик (подневная витрина сотрудника)
- `usr_cross_data.regrettable_n_non_regrettable_base` — разметка regrettable / non-regrettable
- `prod_v_hrmart.legal_position_dismissal_reason` — причины увольнений
- `prod_v_sse_crossdata.mdm_employee_residence` — город и макрорегион (только для трансформеров)
- `prod_v_sse_crossdata.legal_position_vacation` — накопленные дни отпуска по позиции (версии; метрика «Накопленный отпуск»)

#### Target (ClickHouse, база Proteus CROSS)
| Таблица | Что внутри |
|---|---|
| `hrbp_hub_cube` | путь юнита × 6 разрезов численности → массивы компонентов метрик (24 мес + 24 нед) |
| `hrbp_hub_attr` | то же × атрибут для трансформеров (грейд, стаж, город…), только месяцы |
| `hrbp_hub_attr_top` | свёртка атрибутов по всей ветке юнита без разрезов — для корней зон HRBP, компании, блоков и больших веток: трансформер открытого юнита без чтения листового куба |
| `hrbp_hub_base` | база сравнения: вся компания по 6 разрезам, без пути (строк — сколько комбинаций разрезов, тысячи) |
| `hrbp_hub_unit` | справочник юнитов: имя, уровень (1 — компания, 3…12), родитель, путь, численность сейчас, число детей, размер поддерева, есть ли свёртка атрибутов |
| `hrbp_hub_access` | логин → роль и корни зоны (RLS внутри датасета) |
| `hrbp_hub_kpi` | цели KPI (реестр правится в параграфе «KPI · реестр целей») |
| `hrbp_hub_calendar` | 48 слотов: что значит позиция в массиве |
| `hrbp_hub_nr_people` | уволенные без причины с 1 января (и свежие — «дозревает»): rk сотрудника, даты найма и увольнения, уровни 3–6, путь и разрезы — список в отчёте |

Остаётся в GP (не выгружается, отчёт не читает): `hrbp_hub_hrbp_viewers` — HRBP → кто видит его данные
(HRBP с зоной выше, супер-HRBP, админы), вся зона или часть, руководитель ли по структуре, кто в связи старший
(в должности — «старший»).

#### Порядок
Параметры → календарь → строки источника → отпуска → справочник юнитов → зоны HRBP → кто видит HRBP →
увольнения → когорты найма → события по слотам → куб и база → куб атрибутов и его свёртка → цели →
проверки (падают делением на ноль) → выгрузка в ClickHouse → права → удаление времянок.

Расписание: ежедневно после обновления `mdm_employee_structure_d`.
Подробности — репозиторий HRBP_HUB, `docs/architecture.md`.
